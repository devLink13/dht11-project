| Método                                               | Descrição                                                                                   | Uso                                                   | Parâmetros                                             |
|------------------------------------------------------|---------------------------------------------------------------------------------------------|-------------------------------------------------------|--------------------------------------------------------|
| `begin()`                                            | Inicia a comunicação com o sensor DHT.                                                      | `dht.begin();`                                         | N/A                                                    |
| `readTemperature(bool isFahrenheit = false, bool force = false)` | Lê a temperatura. Retorna em Fahrenheit se `isFahrenheit` for `true`. Pode forçar a leitura. | `float temp = dht.readTemperature();`                 | `isFahrenheit` (opcional), `force` (opcional)          |
| `readHumidity(bool force = false)`                   | Lê a umidade. Pode forçar a leitura.                                                        | `float humidity = dht.readHumidity();`                | `force` (opcional)                                     |
| `computeHeatIndex(float temp, float humi, bool isFahrenheit = false)` | Calcula a sensação térmica com base na temperatura e umidade.                                | `float heatIndex = dht.computeHeatIndex(temp, humi);` | `temp`, `humi`, `isFahrenheit` (opcional)              |
| `computeDewPoint(float temp, float humi)`            | Calcula o ponto de orvalho com base na temperatura e umidade.                               | `float dewPoint = dht.computeDewPoint(temp, humi);`   | `temp`, `humi`                                         |
| `convertCtoF(float c)`                               | Converte a temperatura de Celsius para Fahrenheit.                                          | `float tempF = dht.convertCtoF(temp);`                | `c`                                                    |
| `convertFtoC(float f)`                               | Converte a temperatura de Fahrenheit para Celsius.                                          | `float tempC = dht.convertFtoC(tempF);`               | `f`                                                    |
| `read(bool force = false)`                           | Realiza uma leitura completa do sensor DHT. Pode forçar a leitura.                          | `dht.read(true);`                                      | `force` (opcional)                                     |
